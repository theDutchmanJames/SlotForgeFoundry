Bridges in the Track Planner are quicker to build, and there is a second kind of bridge support.

## What's new

- **Bridges follow the climb:** a new straight carries on climbing or descending at the same rate as the piece it joins. Set the ramp once and click in the rest.
- **Supports are copied:** a lifted piece takes the same support count and type as the piece before it.
- **Peg supports:** a new support type with one post under each road edge, in pairs, next to the full-width block.
- **Your peg size:** set the peg width and length from 5 to 100 mm, for example 30 × 30 or 30 × 50.
- **Angled tops:** the top of every peg follows the slope of the road above it.

## Details

**Following the climb.** In the Track Planner, set the lifts on one straight under **Bridge & approaches**, for example 0 to 25 mm. Every straight you place after it carries on at the same rate: 25 to 50, 50 to 75, and so on. A descent works the same way and stops at the table.

- A corner cannot slope, so it stays level at the height it joins.
- After a level piece the next straight is level too. For a bridge you set the climb once, the level deck once and the descent once.
- To change a piece afterwards, select it and enter its lifts as before.

**Peg supports.** Select a section and choose **Bridge & approaches → Support type → Two pegs**. The full-width block is still there and is still the default.

- Pegs stand in pairs, one under each road edge and flush with the side, so a support count of 2 gives four pegs.
- **Peg width** is the size across the road and **Peg length** is the size along it. They start at 20 × 20 mm.
- A road too narrow for two pegs of that width with a gap between them gets full-width blocks.
- Peg supports are in the Track Planner. The supports of a freeform figure eight still use blocks.

Layouts saved in earlier versions open unchanged, with their blocks and lifts as they were.

The [user guide](https://github.com/theDutchmanJames/SlotForgeFoundry/blob/v1.4.0/docs/GUIDE.md) explains bridges in the Track Planner.

## Verification

806 unit tests passed on Windows, among them a run of straights that carries on a climb and a descent, and real builds of pegs measured at the size that was set. The browser stages clicked through the shipped app with networking disabled.

No peg has been test-printed. A tall, slim peg tips more easily than the full-width block; choose a larger peg for high bridges.

The macOS and Linux downloads are built and tested by GitHub Actions after this release is published, on each operating system.

Foundry is not code-signed. On Windows, choose **More info → Run anyway**. On macOS, use **System Settings → Privacy & Security → Open Anyway** the first time. On Linux, mark the AppImage as executable (`chmod +x`). The SHA256SUMS files list each download's checksum.

Your Library, layouts and settings carry over from earlier versions.
