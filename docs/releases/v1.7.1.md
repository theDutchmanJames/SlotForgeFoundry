A roof billboard prints face up, so its text can be raised like any sign.

## What's new

- **Roof billboards:** the two fins behind a roof billboard are parts of their own, so the board prints face up and its text is raised or cut in, as you choose.

## Details

**Roof billboards.** Until now the fins were part of the billboard, so it could only print face down and its text was always carved in V-grooves. Now the board prints flat on its back with its face up, and **Sign text** is raised 0.6 mm or, with **Cut in, not raised**, 0.6 mm deep, like a sign along the wall. Each fin prints lying on its side; glue it flat against the back of the board, 3 mm in from its end, its long side on the roof behind. The kit's README says where they go. A billboard saved before keeps its settings and is built the new way when opened. The Container café, the Refreshment kiosk, the Twin kiosk, the Ticket office and the Timing box have new pictures in **Start from**.

The [user guide](https://github.com/theDutchmanJames/SlotForgeFoundry/blob/v1.7.1/docs/GUIDE.md) explains every setting.

## Install

| System | Installer | Portable app |
| --- | --- | --- |
| Windows | `SlotForgeFoundry-1.7.1-Setup-x64.exe` | `SlotForgeFoundry-1.7.1-Portable-x64.exe` |
| macOS (Intel and Apple Silicon) | `SlotForgeFoundry-1.7.1-mac-universal.dmg` | `SlotForgeFoundry-1.7.1-mac-universal.zip` |
| Linux (x64) | `SlotForgeFoundry-1.7.1-linux-amd64.deb` | `SlotForgeFoundry-1.7.1-linux-x86_64.AppImage` |
| Linux (ARM) | `SlotForgeFoundry-1.7.1-linux-arm64.deb` | `SlotForgeFoundry-1.7.1-linux-arm64.AppImage` |
| Any browser | `SlotForge-Foundry-1.7.1.zip`: extract it and open **SlotForge Foundry.html** | |

Foundry is not code-signed. On Windows, choose **More info → Run anyway**. On macOS, use **System Settings → Privacy & Security → Open Anyway** the first time. On Linux, mark the AppImage as executable (`chmod +x`). The SHA256SUMS files list each download's checksum.

Your Library, layouts, buildings and settings carry over from earlier versions.
